# TIPE-2026
Sujet de TIPE sur la résolution du jeu du Wordle.
Le but de ce projet est de proposer un algorithme de résolution du jeu du Wordle. L'algorithme est a retrouver dans le fichier "Wordle.py". Le code se déroulant de manière chronologique dans l'avancement du projet les fonctions les plus complexes se trouvent à la fin de celui_ci.
